# 13th Chamber Chain - block explorer snapshot

A static snapshot of a node running the 13th Chamber Proof-of-Quantum-Work chain:
QSAM (1,000,000,000, transferable) and QBTC (21,000,000, non-transferable) in one
ledger, with every block carrying its own quantum work proof.

This page is baked, not live. Every API response was captured from a real node, so
the explorer renders with no server behind it. Mining, gossip, the Kotlin verifier
and the self-replicating policy engine live in the private source repository.
